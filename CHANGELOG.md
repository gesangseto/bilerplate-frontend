# CHANGELOG

All notable changes to the MERTRACK Web project are documented in this file.

## [4.3.x] - Branch v4.3

### NEW FEATURE

- **Notification System**
  - Penambahan menu Notifikasi (Notification Channel, Notification Template, Notification Trigger).
  - Panel WhatsApp pada Notification Channel.
  - Konfigurasi penerima notifikasi berbasis menu (menu-based recipients).
  - Penambahan shortcut text pada template pesan notifikasi.
  - Perpindahan halaman & resource notifikasi dari menu System ke menu Notification.
- **Label Print**
  - Tombol Preview pada Print Label.
  - Rotasi preview label -90 / +90 derajat.
- **Queue BPOM**
  - Tombol Skip untuk melewati error pada picking report BPOM.

### Improvement & Fixes

- **WhatsApp Connection**
  - Perbaikan koneksi WhatsApp dan penataan ulang tampilan (restyle) System Config.
- **Lainnya**
  - Perbaikan URL tanpa `#` dan perbaikan bug logout saat cache masih tersimpan.
